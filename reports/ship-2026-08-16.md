# Ship record — 2026-08-16 board-approved batch

Board approved all five moves from the 2026-08-16 daily pulse ("everything is
board approved. Go ahead and fix it, deploy it, and ship it"). This is the
SD-2 before-snapshot: baseline numbers recorded before deploy so the
after-measurement has something honest to compare against.

## What shipped

1. **Mod-grid default page size 20 → 16** (`app/page.tsx`)
   Fewer below-the-fold Content-unit injections per pageview; the whole grid is
   one `.mv-ads` container, so a 5-row default pushed several injected ads into
   territory almost nobody scrolls to. Selector options now 16/50/100 — users
   can still opt into bigger pages.
2. **Mediavine rep email** — asked publishers@mediavine.com for an OAE
   density/viewability review of the Content unit (site 14318). Sent from the
   operator's Gmail, human voice.
3. **Cron wrapper network-readiness guard**
   (`scripts/agents/run-affiliate-daily-pulse.sh`, `run-mediavine-daily-report.sh`)
   Waits up to 90s for the network before the first fetch — kills the launchd
   wake-from-sleep race that produced false-red pulses Aug 10–16.
4. **Affiliate kill-rule recalibration + bare-Logitech catalog + selective
   reactivation** (`scripts/affiliate-optimize.ts`, `scripts/impact-sync-catalog.ts`,
   new `scripts/reactivate-impact-offers.ts`)
   Low-CTR bar changes from absolute 0.05% (the retired Amazon catalog's CTR,
   ~6x this site's real CTR) to relative: 0.5x site-wide lifetime average CTR,
   recomputed each run. Bare Logitech (Impact contract 8585) gets its first
   deep-link offer (POP Keys, verified URL + image). Offers unfairly retired
   under the old bar and clearing the new one get reactivated.
5. **GA4 scroll-depth instrumentation on /go/[modId]**
   (`app/go/[modId]/GoClient.tsx`) — `go_scroll_depth` events at 25/50/75/90%,
   fired once per threshold per pageview. Pure measurement; decides whether the
   below-video ad block on the interstitial is worth moving.
