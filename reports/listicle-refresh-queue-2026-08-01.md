## Standing rules for every refresh
1. Match the title/H1 to the query language the data shows, don't guess.
2. Real content updates before date bumps — Google ignores cosmetic
   "updated 2026" stamps without changed content.
3. Crosslink the matching collection page (differentiated-pair pattern)
   and any catalog mod pages ranking for the same intent.
4. One intent, one page — check for cannibalizing siblings before
   expanding a post (see the legacy-vs-collection report for the
   pattern's history).
5. After each refresh: request indexing in GSC, log the date, compare
   position at +14 and +28 days.
