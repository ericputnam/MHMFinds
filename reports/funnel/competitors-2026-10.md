## UX / download friction

Budget-limited to 1 sampled mod per competitor this run (not the full 3-mod average the spec
calls for — flag for next month to complete the other 2 per site).

| Site | Clicks to file | Friction observed |
|---|--:|---|
| CurseForge | ~1-2 | none — no login, no timer, no interstitial on sampled page |
| The Sims Resource | 5+ | login required, email verification, "turn off ad-blocker" gate, 3 separate required-items downloads; VIP tier collapses this to one click |
| SimsFinds | ~2 | countdown ("wait seconds... or skip the wait with Premium"), account creation encouraged but not confirmed-mandatory |
| ModTheSims | ~1-2 | none — direct file link, static ad banner only, voluntary "Ads Free" donation |
| **Ours** | 2 (mandatory) | `/mods/[id]` → `/go/[modId]` 10-15s countdown with Mediavine ads → external host; no login required |

## Monetization

- **CurseForge**: ad-supported (CurseForge/Overwolf app); no per-item paywall observed.
- **The Sims Resource**: freemium — ads + mandatory ad-blocker-off for free tier, paid VIP membership removes ads and the required-items friction.
- **SimsFinds**: freemium — ad-supported with a skippable countdown timer; Premium subscription removes the wait.
- **ModTheSims**: ad-supported, voluntary donation-based "Ads Free" option, no paid tier gating downloads.
- **Patreon creators** (BADDDIESIMS, Syboulette, dreamgirl sampled): patron paywall window (21-day / 3-week early access) then free public release; $3+/mo entry tier.
